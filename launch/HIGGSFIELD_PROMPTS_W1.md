## ⚙️ Higgsfield run protocol

For maximum efficiency:

1. **Batch session:** Block 45-60 min on Day 3 morning. Don't try to do these one at a time across the week — context-switch tax is real.

2. **Order to run:**
   - Prompts 01-04 first (Day 3-5 content, immediate need)
   - Prompts 05-07 second (Day 6-7, less urgent)
   - Bonus last (standby asset)

3. **Per-prompt timing:**
   - Paste prompt: 5 sec
   - Set params: 5 sec
   - Generate: 60-90 sec
   - Preview + download: 15 sec
   - Save to local folder: 5 sec
   - **Total: ~2 min per prompt × 7 = ~14 min**

4. **If quality is bad on any prompt:** regenerate ONCE with same params. If still bad, tweak the prompt slightly (add "high detail" or "8K" suffix). Don't regenerate more than 2x — Higgsfield credits aren't infinite.

5. **Save the seed values** for any video you love — same seed + tweaked prompt = consistent style for a series.

## 🚨 Brand-safety on Higgsfield outputs

Quick check before posting any AI-video:
- [ ] No real athlete's face (unrecognizable silhouettes only)
- [ ] No real team logos (generic basketball/football/etc. only)
- [ ] No "guaranteed lock" language anywhere
- [ ] No betting amounts shown ($X bet ≠ Pick1's promise)
- [ ] Acid green color is present (#d4ff3a, the Pick1 brand color)
- [ ] No gambling-warning-triggering language (just "AI predictions" / "calibrated forecast")

If a generation violates any of these, regenerate or pick a different visual.
